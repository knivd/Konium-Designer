# Format status

**Verified** = checked against an independent implementation or real Altium output.
**Cross-checked** = our read order matches KiCad's open-source Altium importer (facts only; our own code).
**Self-consistent** = our reader and writer agree, from public descriptions; not yet checked on
real files. Nothing below is "verified" against Altium itself until the corpus runner passes and
edited files open cleanly in a licensed Altium.

## First corpus pass checklist

1. Run `tests/tools/corpus.ts` on a spread of projects (old Summer 09 → current, small → large).
2. Any `DIFF` on unmodified round-trip is a framing bug — fix before anything else.
3. For PcbDoc: `declared` ≠ `decoded` points at a layout problem in that storage.
4. Open each PcbDoc in Konium and Altium side by side; compare pads, arcs, texts.
5. Place a track in Konium, save, open in Altium, run DRC: the first real write test.
